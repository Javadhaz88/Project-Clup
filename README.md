# کلوپ حامد — Android

اپ اندرویدی WebView برای سایت رسمی [cluphamed.ir](https://cluphamed.ir).

## تغییرات این نسخه
- رابط تیره با جزئیات طلایی و نوار پیمایش فارسی.
- حفظ سایت رسمی داخل WebView؛ فایل‌های سایت تغییر نمی‌کنند.
- خانه، نشانک‌گذاری، صفحه‌های ذخیره‌شده، اشتراک‌گذاری و تماس.
- بهبود پیام وضعیت اتصال و نمایش خطاهای صفحه اصلی.
- محدودکردن محتوای ترکیبی ناامن و غیرفعال‌بودن دسترسی فایل محلی در WebView.
- **هیچ گزینه یا پیاده‌سازی دانلود در اپ وجود ندارد.**
- حفظ انتخاب فایل برای فرم‌های وب، در صورت نیاز سایت.

## ساخت APK
هر بار که به شاخه `main` تغییر ارسال شود، GitHub Actions نسخه Debug را می‌سازد.

1. وارد بخش **Actions** همین مخزن شو.
2. اجرای آخر با نام **Build Club Hamed APK** را باز کن.
3. در بخش **Artifacts**، فایل `Club-Hamed-debug-APK` را دریافت کن.
4. ZIP آرتیفکت را باز کن و `app-debug.apk` را نصب کن.

نسخه Debug برای آزمایش است و با کلید انتشار اختصاصی امضا نشده است. برای نصب روی گوشی‌ای که نسخه قبلی با امضای متفاوت دارد، ممکن است لازم باشد نسخه قبلی را حذف کنی؛ قبل از حذف، اطلاعات محلی مهم را در نظر بگیر.
